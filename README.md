# SDN Campus Project

Redes SDN basadas en ONOS, Mininet, RADIUS y Suricata.

## Estructura
- `apps/`: Código fuente de aplicaciones (ONOS, IDS, portal, agentes).
- `infra/`: Infraestructura (compose, init scripts).
- `overlays/`: Configuraciones específicas de hitos (r1, r2, r5).
- `tests/`: Pruebas integradas.
- `docs/`: Documentación.
